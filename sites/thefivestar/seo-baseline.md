## Google Search Console

- **Historical property:** `https://thefivestar.com` (URL-prefix), connected via the
  **Site Kit by Google** plugin. The Google account that authorized Site Kit *owns
  this property and holds the full history.* To recover it: **WP Admin → Site Kit →
  Settings** shows the connected account; add SA `gsc-readonly@mortgagepoint.iam.gserviceaccount.com`
  to that property, then point the export at `GSC_PROPERTY=https://thefivestar.com`.
- **New property (2026-06-16):** `sc-domain:thefivestar.com`, owned by
  it.manager@dsnews.com, SA added. Collects **forward only** — no backfill.
- Export tool: `scripts/gsc-export.sh` (read-only service account). Semrush (below)
  is the authoritative *historical* baseline until the Site Kit property is recovered.

## AIOSEO Pro configuration checklist

- [ ] Homepage meta title and description customized (not auto-generated)
- [ ] Schema type: Organization or EducationalOrganization
- [ ] Social profiles linked (LinkedIn, Facebook)
- [ ] Open Graph images set for homepage and key landing pages
- [ ] Breadcrumbs enabled and displaying
- [ ] Yoast SEO removed (eliminates duplicate meta conflict)
- [ ] IndexNow activated (fast Bing/Yandex indexing)
